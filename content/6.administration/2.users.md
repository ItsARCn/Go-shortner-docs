# User Management

The **Users** view in the Admin Control Center (`/admin/users`) provides tools to inspect registered accounts, view activity history, and adjust access levels.

---

## Searching and Filtering

Administrators can navigate large rosters of users using the toolbar controls:
- **Instant Search**: Matches real-time against first name, last name, and email address.
- **Status Filter**: Filter users by operational state:
  - **All Users**
  - **Active** (in good standing)
  - **Timed Out** (temporarily restricted)
  - **Banned** (permanently barred)
- **Role Filter**: Group users by `user`, `moderator`, or `super_admin`.

---

## User Detail Roster

Each user record provides key diagnostic attributes:
- **User Identity**: Full name, email address, and authentication provider (`email` vs `google`).
- **Role Badge**: Visual indicator of current permissions (`User`, `Moderator`, `Super Admin`).
- **Quota Usage**: Live tally of links created in the current month vs quota ceiling.
- **Account Timestamps**: Account creation date, profile update date, and last recorded login timestamp.

---

## Role Assignment (Super Admin Only)

`super_admin` accounts have exclusive authority to assign or revoke administrative permissions via the role management dropdown:

```
[ Promote User ]
├── Make Moderator  -> Grants access to link/user moderation and report queues
├── Make Super Admin -> Grants complete system ownership and audit log viewing
└── Demote to User  -> Restricts account to standard registered user limits
```

::caution
Exercise extreme care when promoting accounts to `super_admin`. Super Admins can manage all user roles and view security audit logs.
::
