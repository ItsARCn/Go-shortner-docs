# Renewing Links

One of GO Shortener's most powerful capabilities is **Preserved Code Renewal**. If a link expires, its registered owner can restore it immediately without having to generate a new short code or update distributed URLs.

::tip
**Zero Quota Penalty**: Renewing an expired link does **not** consume any of your monthly link-creation quota. Quota is charged only upon the initial creation of a link.
::

---

## How Renewal Works

1. Open your **User Dashboard** at `https://go.arcn.online/dashboard`.
2. Use the status filter dropdown to view **Expired** links.
3. Locate the expired link you wish to restore and click **Renew Link**.
4. In the renewal modal, choose a new expiration window:
   - 7 Days
   - 30 Days
   - 3 Months
   - 6 Months
   - 1 Year
5. Click **Confirm Renewal**.

---

## What Happens Behind the Scenes?

- **Short Code Kept Intact**: The original short code (`go.arcn.online/K8xP2q`) remains identical. Anyone who visited the link while it returned a 410 Gone page will now seamlessly be redirected (HTTP 302) to the target destination again.
- **Analytics Retained**: Historical click statistics, device breakdowns, and referrer data are fully preserved and will continue accumulating new impressions.
- **Status Restored**: The link's database record updates `status = "active"` and recalculates `expires_at = now() + duration`.
